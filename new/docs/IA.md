# STUDY MATE 화면 구조 (IA)

> 작성일: 2026-10-11
> 상태: 확정 (만들면서 변경 가능)

---

## 1. 전체 화면 흐름

```
[처음 방문]
 ├ 로그인          이메일+비번 / 구글
 ├ 회원가입        이메일+비번 → 인증 메일 확인
 └ 비밀번호 찾기   이메일로 재설정 링크

[로그인 후]
 ├ 내 그룹 목록   ← 로그인하면 항상 여기부터
 │   ├ 그룹 만들기  (그룹 이름 입력 → 초대 링크 받기)
 │   └ 코드로 참여  (초대 코드 입력)
 │
 ├ 그룹 화면  ─ 상단 탭: [주간] [월간] [관리]
 │   ├ 주간 장부
 │   ├ 월간 현황
 │   └ 그룹 관리
 │
 ├ 내 계정
 │
 └ 초대 링크로 들어옴
     → (로그인 안 됐으면 로그인/가입)
     → 그룹 닉네임 입력
     → 그룹 가입 완료 → 바로 그룹 화면
```

---

## 2. 화면별 내용

### 2.1 로그인 / 회원가입 / 비밀번호 찾기
- 로그인: 이메일, 비밀번호, [구글로 로그인]
- 회원가입: 이메일(실사용 메일), 비밀번호 → "인증 메일을 보냈어요" 안내
- 비밀번호 찾기: 이메일 입력 → 재설정 링크 발송 → 새 비밀번호 설정

### 2.2 내 그룹 목록
- 가입한 그룹 카드 목록 (그룹 이름, 내 역할: 방장/멤버, 멤버 수)
- [그룹 만들기], [코드로 참여]
- 가입한 그룹이 없으면: 빈 화면 안내 + 두 버튼 강조

### 2.3 그룹 화면 – 공통 상단
- 그룹 이름 (누르면 그룹 목록으로)
- 디데이 최대 3개
- 탭: [주간] [월간] [관리]

### 2.4 주간 장부 (기존 화면 기반)
- 주차 이동 ‹ ›
- 그룹 규칙 요약: 최소 공부시간 / 상점 기준(상점 꺼져 있으면 숨김) / **벌금 단위**
- 멤버 카드: 요일별 체크(공부시간·시작시간·상점), Day Off, 요일별 목표 시작시간, 주간 점수·이월·벌금
- 수정 가능 여부는 그룹의 권한 모드에 따름
  - 자율 모드: 방장은 전체, 멤버는 본인 카드만
  - 방장 관리 모드: 방장만

### 2.5 월간 현황 (신규, 별도 탭)
- 월 이동 ‹ ›
- 멤버별 요약표: 벌점 합계 / 상점 합계 / 순점수 / 벌금 금액 / 납부 여부
- (방장) 납부 체크

### 2.6 그룹 관리
- 멤버 목록 (닉네임, 방장 표시)
- 초대 링크 복사 / 초대 코드 보기
- 내 그룹 닉네임 변경, 그룹 나가기
- **(방장만)**
  - 규칙 설정: 최소 공부시간, 상점 켜기/끄기, 상점 기준 시간, 벌금 단위, 기본 시작시간
  - 디데이 관리 (최대 3개)
  - 수정 권한 모드: 자율 / 방장 관리
  - 방장 지정·해제·양도, 멤버 내보내기
  - 초대 코드 재발급

### 2.7 내 계정
- 이메일 (변경 불가 표시)
- 비밀번호 변경 (이메일 가입자만)
- 로그아웃, 회원 탈퇴

---

## 3. 확정된 결정

| 항목 | 결정 |
|---|---|
| 로그인 후 첫 화면 | 항상 **내 그룹 목록** |
| 월간 현황 | **별도 탭** |
| 그룹 내 이름 | **그룹마다 따로** 닉네임 설정 |
| 규칙 공개 범위 | 주간 화면 상단에 벌금 단위까지 표시. 관리 탭은 모두에게 보이고 수정 버튼만 방장에게 노출 |
